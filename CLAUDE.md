# Reel project rules (apply to every script)
- Length: 40 seconds, vertical 9:16 reel/short format (~100–110 spoken words).
- Hook in the first 2 seconds: a question or surprising claim on screen + voice, no intro/logo.
- Show all theories/answers when a topic has several; end with a loop or next-question CTA.
- Every script: timed scene table (time, visual, on-screen text, voiceover).
- Mark unverified facts with ⚠ and verify before production.
- Scripts live in scripts/, topic ideas in research/topic-ideas.md.
