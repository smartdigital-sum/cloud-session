# Long-form YouTube videos

Faceless narrated videos (3–4 min, 16:9), each with a ~60s reel version and English, Hindi and Assamese voiceover. Rules: [CLAUDE.md](CLAUDE.md).

**One folder per series, one folder per video.** Every series folder has the same layout:

```
<series>/
├── README.md          ← video index + open fact checks before production
├── topic-ideas.md     ← the 10 ideas and which are done
├── publishing-kit.md  ← titles, descriptions, schedule, pinned comments (added when the series is finished)
└── NN-slug/           ← one folder per video, always these four files:
    ├── long-video-script.md
    ├── long-video-voice.md
    ├── short-reel-script.md
    └── short-reel-voice.md
```
